# Producción 1.5.2+13 — 2026-10-07

## Cambio móvil

Habilita Registrar gabinete y Revisión de hidrante en producción para residentes
Field Construction. Conserva sesión Field, coincidencia del usuario del perfil,
autorización de API, catálogo descargado y aislamiento del caché por usuario.
Contractors y sesiones admin no reciben acceso por equivalencia reviewer.

El primer acceso requiere conexión al backend de gabinetes. Una respuesta 404/503
al obtener el catálogo muestra indisponibilidad con reintento y no autoriza una
sesión nueva. Los borradores existentes se conservan; no se dispara sincronización
automática después de fallar esa descarga. 401/403 revoca el acceso local.
Los mecanismos existentes de cola offline, fotografías, idempotencia y versionado
no cambian.

## Dependencia de despliegue

El usuario confirmó que realizó las migraciones de producción y desplegará
manualmente el backend. Esta intervención no ejecuta SQL ni despliega la API.
Requiere API Gabinetes y conservación de piezas compatibles (ace958c o posterior).
La migración realizada no sustituye el despliegue del backend.
